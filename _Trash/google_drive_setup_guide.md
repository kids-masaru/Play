# Google Drive API 設定ガイド（自動化用）

GitHub Actions で動くスクリプトが、あなたの Google ドライブに CSV ファイルをアップロードできるようにするため、**サービスアカウント**を作成します。

---

## 1. プロジェクトを作成する

1. [Google Cloud Console](https://console.cloud.google.com/) を開く
2. 左上の「プロジェクトを選択」をクリック → **新しいプロジェクト** を選ぶ
3. プロジェクト名を `BoatRaceAuto` にして、**作成** をクリック

---

## 2. API を有効にする

1. 左メニューから **APIとサービス** → **ライブラリ** を開く
2. 検索ボックスに **「Google Drive API」** と入力
3. 表示されたら **有効にする** をクリック
4. 同様に **「Google Sheets API」** も検索して **有効にする**（今後のため推奨）

---

## 3. サービスアカウントを作成する

1. 左メニューから **APIとサービス** → **認証情報** を開く
2. 上部の **認証情報を作成** → **サービスアカウント** をクリック
3. サービスアカウント名に `boat-race-bot` と入力
4. **作成して続行** をクリック
5. ロール（役割）で **基本** → **編集者** を選択（ファイルの読み書きができるようになる）
6. **完了** をクリック

---

## 4. 鍵ファイル（JSON）を取得する

1. 作成したサービスアカウントのメールアドレス（例：`boat-race-bot@〇〇〇.iam.gserviceaccount.com`）をクリック
2. **キー** タブを開く
3. **鍵を追加** → **新しい鍵を作成** をクリック
4. **JSON** を選択 → **作成** をクリック
5. ファイルが自動的にダウンロードされます。**これは大切に保管してください！**（ロボットの「パスワード」です）

---

## 5. Google ドライブのフォルダを共有する

1. ブラウザで **Google ドライブ** を開く
2. `boat_race_data` という名前のフォルダを作成（まだなければ）
3. そのフォルダを右クリック → **共有** をクリック
4. 「ユーザーやグループを追加」欄に、**ステップ4で作成したサービスアカウントのメールアドレス**をコピペ
5. 権限が **編集者** になっていることを確認
6. **送信** をクリック（「通知する」のチェックは外してOK）

---

## ✅ 完了したら

ダウンロードした **JSONファイル**（鍵）を教えてください。次のステップに進みます！
